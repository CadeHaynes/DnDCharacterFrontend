Features:
- Viewing of all stored characters
- Individual page to show all stored information on a character
- Able to add, edit, and delete items/abilities for characters
- Able to add, edit, and delete characters

Tools:
- React
- React Router
- Fetch API

Prerequisites:
- Node.js
- DnDCharacterManager (backend)

Setup
- cd DnDCharacterFrontend
- npm install
- npm run dev
- Frontend url should be http://localhost:5173
- Backend url should be http://localhost:5062
